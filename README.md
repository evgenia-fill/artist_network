## Фронтенд «Лаборатория»

Для локального запуска и сборки нужны Node.js 22.12+ и npm. Интерфейс React работает в браузере. Vite запускает сервер разработки и собирает статические файлы.

Из корня репозитория в PowerShell:

```powershell
npm.cmd --prefix web ci
npm.cmd --prefix web run dev:mock
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173). В моковом режиме можно переключать проекты, применять правки, сохранять и открывать версии. Тестовые данные находятся в `web/mocks/fixtures.js`, а изменения хранятся в памяти сервера Vite до его перезапуска. Для этого режима .NET, база данных и S3 не нужны.

`npm.cmd --prefix web run build` создаёт сборку в `web/dist`. Команда `npm.cmd --prefix web run preview:mock` раздаёт эту сборку с моками по адресу [http://127.0.0.1:4173](http://127.0.0.1:4173).

### Подключение .NET API

Запросы интерфейса собраны в `web/src/editorApi.js`. Комментарии в этом файле указывают действующие маршруты изображений и контракты, которые предстоит согласовать для профиля, проектов, друзей и сохранения всех правок. Маршрут `/api/editor` и его подмаршруты сейчас обслуживает моковый API.

`npm.cmd --prefix web run dev:api` отключает моки и проксирует `/api` на `http://localhost:5193`. Другой адрес можно задать через переменную окружения `PIXELFLOW_API_TARGET`. Для работы редактора в этом режиме сначала нужно подключить серверные маршруты в `editorApi.js`.
