## Фронтенд

Запустите API и выполните в каталоге `web`:

```sh
npm ci
npm run dev
```

Vite проксирует `/api` на `http://localhost:5193`. Для другого адреса задайте
`PIXELFLOW_API_TARGET` в окружении Vite или в `web/.env.local`. При раздаче
сборки `npm run build` настройте проксирование `/api` на том же домене.

Редактор загружает JPEG, PNG и WebP размером от 1 байта до 10 МиБ
(10 485 760 байт). Поворот и отражение сохраняются как новая версия.
Чтобы открыть предыдущую версию, выберите её в истории. Кнопка «Сбросить»
возвращает оригинал. API предоставляет историю по идентификатору изображения,
поэтому список загруженных изображений привязан к браузеру.

Для демонстрации друзей, лайков и цветокоррекции используйте `npm run dev:mock`.

Для локальной сборки API нужна реализация `LocalFileStorage`, на которую
ссылается `PixelFlow.Infrastructure`. Сейчас её исходника нет в репозитории.
Фронтенд можно направить на уже запущенный совместимый API.
